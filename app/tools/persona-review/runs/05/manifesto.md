/batches must read like the Financial Times of cryptographic settlement, not a database dump in a card costume. A sealed batch is a public record — set it like one. The page asks for an editorial masthead with an ISO date, an italic Source Serif 4 dek that names the privacy clause once, a standfirst sentence that interleaves figures into prose, a run-of-paper column where each entry is a numbered paragraph rather than a card, and a marginalia rail that holds search and pagination off the evidence. Empty, loading, and error states are not utility messages — they are short editor's notes about what is on the press today. Hierarchy persuades. Restraint signs the page.
