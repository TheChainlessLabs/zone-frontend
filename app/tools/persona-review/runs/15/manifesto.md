Omega does not need more screen ideas. It needs one product grammar. The trade ticket, portfolio rows, batch records, account settings, and every blocked state should feel derived from the same system: stable object headers, repeatable status treatment, predictable actions, and no decorative exceptions. When a page invents a new hero, a new footer box, or a new control rhythm, coherence leaks. The right standard is not “pleasant.” It is operational: every surface should make the same kinds of facts look and behave the same way. If that holds, the product starts to feel institutional. If it does not, it remains a collection of competent mockups.
