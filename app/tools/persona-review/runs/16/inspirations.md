# Inspirations - Omar El-Sayed

## Competitive HUD and status logic

- https://support-valorant.riotgames.com/hc/en-us/articles/4413936440467-VALORANT-UI-Settings-FAQ - Riot gets the rule right: phase-specific information belongs exactly where pressure spikes, not buried in soft copy.
- https://support.discord.com/hc/en-us/articles/7931156448919-Activity-Sharing-on-Discord-FAQ - Discord treats presence like a first-class layer, and that is exactly how proof state should behave here.
- https://support.discord.com/hc/en-us/articles/360035407531-Custom-Status - Status overriding other status is a useful reminder: the loudest live signal must win the lane.

## Launcher and account-density patterns

- https://us.support.blizzard.com/en/help/article/25949 - Battle.net is pure launcher discipline: install, patch, repair, queue, all in one accountable frame.
- https://download.battle.net/en-us/desktop - The launcher pitch is blunt and correct: games, friends, updates, news, one roof, no mystery.
- https://store.steampowered.com/libraryupdate - Steam's library home shows how to make dense account surfaces feel active instead of clogged by arranging updates and activity into readable shelves.

## Competitive workflow references

- https://support.faceit.com/hc/en-us/articles/14996885023516-Navigating-FACEIT - FACEIT keeps crucial tools pinned and trims dead chrome, which is the right instinct for a verification dashboard.
- https://support.faceit.com/hc/en-us/articles/17012729714972-FACEIT-Track-Overview - Track proves that advanced stats can stay quick if the top of the page tells me where to look first.
- https://support.faceit.com/hc/en-us/articles/360021886440-How-to-Join-a-Match - Match-room UX lives or dies on stage visibility; Omega's batch flow wants that same certainty.
- https://support.faceit.com/hc/en-us/articles/12348725948572-How-to-join-an-Overwatch-match - FACEIT literally tells players to keep the page open for key notifications; that is the energy `/batches` should carry.

## Performance framing

- https://mobalytics.gg/gpi/ - Mobalytics scores complicated play into named lanes, and Omega should do the same for proof progression.

## Anti-references

- https://www.aesop.com/us/ - Gorgeous pace, wrong pace; this kind of literary merchandising would get a trader killed on a live state surface.
- https://design-guide.publishing.service.gov.uk/frontend-templates/homepage/ - GOV.UK is great at task finding across broad content, but Omega needs state triage, not civic wayfinding.
- https://www.hermes.com/ - Hermes tells object stories with ceremony; ceremony is exactly what must get cut when proof status is on the clock.
