Proof state has to read like a game HUD, not a whitepaper appendix. When a batch is pending, proven, settling, or broken, the interface should announce that condition in one glance with ranked hierarchy, active-stage focus, and motion that teaches progression. Omega already has the right ingredients, but `/batches` still behaves too much like a composed report. Give me a live attestation rail, a choke-point header, and failure modules that seize the screen when something goes wrong. If I have to read paragraphs to know whether the system is safe, the interface already lost.
