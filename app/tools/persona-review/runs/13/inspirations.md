# Inspirations — Caleb's references, in his voice

These are the tabs I keep open. Omega should feel like it earned a slot in this row.

## Action-first crypto-native trading

- https://app.uniswap.org/ — the dominant action module is the entire app; copy that confidence for the order ticket. I want one card that owns the screen, not one card floating on a grid.
- https://github.com/Uniswap/interface — open-source reference for how the swap card composes: pair switch, amount, "you receive", route preview, single CTA. No surprises, no bureaucracy.
- https://www.dextools.io/tutorials/uniswap-v4-the-modular-revolution — v4's modular swap reads as evidence that the action surface can stay small while the engine behind it gets richer. Don't add tabs; add detail under the same card.

## Execution-quality language

- https://swap.cow.fi/ — surplus and solver competition shown as a visible badge, not a footnote. Omega's "midpoint match" deserves the same treatment as CoW's "surplus" — make it the loudest pre-trade element.
- https://docs.cow.fi/cow-protocol/tutorials/arbitrate/solver/solver-engine — the language: solver, batch, settle, surplus. We have the parallel terms — match, batch, seal, attest — and we should use them out loud.
- https://eco.com/support/en/articles/13064300-cow-swap-explained-intent-based-dex-trading-with-mev-protection — confirms the playbook: explain why your execution is better, in the order ticket itself, not in a docs page.
- https://docs.cow.fi/cow-protocol/concepts/how-it-works/protocol-vs-swap — separates protocol from app; Omega's frontend has the same opportunity to brand the *experience* of being inside a TEE-attested batch, not just the protocol.

## Pre-sign clarity / wallet safety

- https://docs.tenderly.co/simulations/transaction-preview — the technical pattern. Simulate the call, render the balance delta, show the user what they're signing. Take this idea and apply it to "what batch you'll land in, what proof you'll get."
- https://cryptoadventure.com/rabby-wallet-review-2026-safer-evm-defi-with-transaction-simulation-risk-scanning-and-auto-chain-switching/ — Rabby's pre-sign balance-change preview is the bar for a confirmation modal in 2026. Omega's order confirmation modal should look like Rabby: this in, this out, this fee, this batch, this proof.
- https://rabby.io/ — wallet brand; the trust comes from showing your work before the signature, not from a security badge.

## Crypto-native polish (warm, not enterprise)

- https://rainbow.me/ — friendly without being childish. Good reference for the float-the-CTA-above-the-tab-bar mobile move and for how to make a serious thing feel approachable.
- https://zora.co/ — the right level of polish for a crypto-native consumer surface. Big, calm, confident type. Few elements, each one earned. Portfolio hero already has this energy; keep going.
- https://www.farcaster.xyz/ — early-adopter culture. Not a UI reference, a social-design reference: the gate should feel like joining a club, not like a permissions error.
- https://medium.com/@combfin/farcasters-frames-are-new-alpha-579ffd6738fd — what "alpha" *feels* like: a thing that just shipped, gated to people in the loop, talked about in DMs. Omega's NFT-pass gate should aspire to this, not to Galxe.
- https://www.theblock.co/post/275971/farcaster-daily-active-users-surge-frames-launch — the receipts: alpha framing actually moves DAU.

## Anti-references — what to avoid, and why

- https://uxmag.com/articles/the-impossible-bloomberg-makeover — Bloomberg's UI works because users are paid to suffer it. Retail crypto isn't. Don't import the void without the density.
- https://www.bloomberg.com/professional/solution/bloomberg-terminal/ — the source. Studied for what *not* to do: yellow-on-black, function codes, no whitespace.
- https://pro.kraken.com/ — professional but emotionally flat. Reading this UI feels like filing taxes. Omega is selling alpha-coded execution, not compliance.
- https://www.trustpilot.com/review/kraken.com — receipts on Kraken Pro UI complaints; users notice when an interface stops feeling alive.
- https://www.fireblocks.com/ — enterprise polish, no warmth. We are infrastructure, not bank-grade-back-office. Different vibe.
- https://www.interactivebrokers.com/ — TradFi bureaucracy energy. Forms, modals, multi-step wizards. We can't afford a single one of these on the trade page.
